# Platform Status and Dependency Matrix

**Last verified: 2026-11-13**

`cfeval` integrates across General Availability (GA) and Preview capabilities in Microsoft 365, Microsoft Fabric, and Microsoft Foundry. Review the lifecycle status, authentication model, and operational constraints of each upstream dependency before adopting a target or scorer in production release pipelines.

## Upstream Platform Matrix (`R1` – `R17`)

| Ref | Capability / Dependency | Lifecycle Status | How `cfeval` Uses It | Key Constraints & Official Documentation |
|---|---|---|---|---|
| `R1`, `R2` | **Microsoft 365 Copilot Chat API** (`POST /beta/copilot/conversations`, `/chat`) | **Preview** (`/beta`) | Default `copilot-chat` target for multi-source Fabric IQ and Work IQ evaluation turns. | Delegated user authentication only (no app-only service principals); Microsoft `/beta` APIs are not supported for production workloads; requires broad Graph read scopes (`Sites.Read.All`, `Mail.Read`, `People.Read.All`, `OnlineMeetingTranscript.Read.All`, `Chat.Read`, `ChannelMessage.Read.All`, `ExternalItem.Read.All`). [Overview](https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/api/ai-services/chat/overview) · [Chat endpoint](https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/api/ai-services/chat/copilotconversation-chat) |
| `R3` | **Fabric IQ in Microsoft 365 Copilot Chat** | **GA** | Routes analytical prompts in M365 Copilot Chat to Power BI semantic models and Fabric data agents. | Requires Microsoft 365 Copilot add-on / Premium licence plus Power BI / Fabric access; semantic model RLS and OLS apply as the signed-in user. [Fabric IQ connector overview](https://learn.microsoft.com/en-us/fabric/iq/connectors/microsoft-365-copilot-overview) |
| `R4`, `R10` | **Power BI Copilot semantic model search & data Q&A** | **GA** | Answers measure, grouping, date-context, and filter questions over approved semantic models. | Restricted/disabled models are excluded from cross-model search (`R10`); curated Power BI **verified answers** can be bypassed when queries route through Fabric IQ (`R4`). [Ask data questions](https://learn.microsoft.com/en-us/power-bi/create-reports/copilot-ask-data-question) · [Semantic model Copilot settings](https://learn.microsoft.com/en-us/power-bi/create-reports/copilot-semantic-models) |
| `R5` | **Fabric IQ MCP Server** (`https://fabriciq.svc.cloud.microsoft/v1/mcp/fabriciq`) | **Preview** | Optional `mcp-agent` / `fabric-iq-mcp` target for structured tool-call (`tool_call`) evaluation. | Delegated user permissions (`Item.Read.All`, `Item.Execute.All`); service principals are not supported. [Fabric IQ MCP server](https://learn.microsoft.com/en-us/fabric/iq/connectors/fabric-iq-mcp) |
| `R6`, `R7` | **Microsoft 365 Copilot Evaluations CLI (`@microsoft/m365-copilot-eval`) & Work IQ Dev Tools** | **Preview** (v2 schema `2.0`) | Optional round-trip golden export (`cfeval golden export --format m365-copilot-eval`) and result import (`cfeval run --target import --from-m365-copilot-eval`). | Node-based CLI (`runevals`); `cfeval` complements it with unit-aware numeric tolerances, `SemanticModelLogs` DAX verification, and paired McNemar gating. [Evaluations CLI overview](https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/evaluations-cli-overview) · [Evaluators](https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/evaluations-cli-evaluators) · [Evaluation overview](https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/evaluation-overview) · [GitHub repo](https://github.com/microsoft/m365-copilot-eval) |
| `R8`, `R9` | **Fabric Workspace Monitoring & `SemanticModelLogs`** | **GA** | Independent engine evidence source (`QueryEnd` DAX text, `SemanticModelId`, `DurationMs`, `CpuTimeMs`, `CorrelationId`, `ApplicationContext`). | Consumes Fabric capacity CU; **30-day default retention**; one monitoring Eventhouse can collect across workspaces; asynchronous ingestion lag (`15`–`90s+`). [Workspace monitoring overview](https://learn.microsoft.com/en-us/fabric/fundamentals/workspace-monitoring-overview) · [Semantic model operation logs](https://learn.microsoft.com/en-us/fabric/enterprise/powerbi/semantic-model-operations) |
| `R11`–`R14` | **Microsoft Foundry Evaluations & Custom Code Evaluators** | **GA / Preview** (custom code evaluators **Preview**) | Optional `--option foundry` cloud evaluation export and Layer 5 judge grading (`src/cfeval/foundry.py`). | Custom code evaluators enforce `< 256 KB` bundle size, `2 min` max per call, `2 GB` RAM, and zero network (`R11`, hence `src/cfeval/scorers.py` is zero-dependency stdlib). Foundry Quality Grader is deprecated (`R13`); Foundry Decisions API is GA (`R14`). [Custom evaluators](https://learn.microsoft.com/en-us/azure/foundry/concepts/evaluation-evaluators/custom-evaluators) · [Cloud evaluation](https://learn.microsoft.com/en-us/azure/foundry/observability/how-to/cloud-evaluation) · [Agent evaluators](https://learn.microsoft.com/en-us/azure/foundry/concepts/evaluation-evaluators/agent-evaluators) · [Foundry Oct 2026 updates](https://devblogs.microsoft.com/foundry/whats-new-in-microsoft-foundry-october-2026/) |
| `R15` | **PyPI SDK Dependency Split (`azure-ai-projects` vs. `fabric-data-agent-sdk`)** | **Packaging constraint** | Optional extras (`pip install -e ".[foundry]"` vs. `".[fabric-data-agent]"`). | `azure-ai-projects` (`2.11+`) requires `openai >= 3`, while `fabric-data-agent-sdk` (`0.1.36a0` alpha) pins `openai < 3`. Install in separate virtualenvs if using both optional SDKs. [azure-ai-projects](https://pypi.org/project/azure-ai-projects/) · [azure-ai-evaluation](https://pypi.org/project/azure-ai-evaluation/) · [fabric-data-agent-sdk](https://pypi.org/project/fabric-data-agent-sdk/) |
| `R16`, `R17` | **Fabric Data Agent & Advanced DAX Generation** | **Preview** (agent eval SDK) / **GA** (advanced DAX Nov 2026) | Optional `fabric-data-agent` target; upstream Fabric IQ replaces the retiring Foundry custom data-agent tool. | Notebook evaluation SDK requires `F2+` capacity (`R16`); Microsoft is retiring the legacy Foundry data-agent custom tool in favour of Fabric IQ (`R17`). [Evaluate a Fabric data agent](https://learn.microsoft.com/en-us/fabric/data-science/evaluate-data-agent) · [Advanced DAX GA](https://community.fabric.microsoft.com/blog/fbc_fabricupdatesblogs/advanced-nl2sql-and-advanced-dax-generation-in-fabric-data-agents-generally-avai/5374654) · [Foundry tool retirement -> Fabric IQ](https://community.fabric.microsoft.com/blog/fbc_fabricupdatesblogs/retiring-the-fabric-data-agent-custom-tool-in-microsoft-foundry-move-to-fabric-i/5374418) |
| — | **Microsoft Fabric Eventhouse (KQL Database)** | **GA** | Durable telemetry store (`EvalRuns`, `EvalQuestions`, `EvalTurnTraces`, `EvalSemanticModelLogs`, `EvalComparisons`). | Requires Fabric capacity (`F2+`); pause dev/demo capacities via bounded leases when idle. |
| — | **Microsoft Fabric Apps** (`app/`) | **Preview** | Optional hosted React scorecard experience (`app/overlay/`). | Preview workload; use standalone local Vite preview (`npm --prefix app/standalone run dev`) or `cfeval report` HTML output when preview workloads are disabled. |
