# Walkthrough & Evaluation Guides (Moved)

Looking for end-to-end walkthroughs and sample datasets? See the Getting Started, How-To, and Sample Kit guides:

- **[Deploy the Scorecard App](how-to/deploy-the-scorecard-app.md)** — Standalone Vite preview (`cfeval demo-data --as-of`) and optional Fabric App hosting.
- **[Transcript Import Quickstart](get-started/quickstart-transcript-import.md)** and **[Use with the Evaluations CLI](how-to/use-with-the-evaluations-cli.md)** — Score pre-captured JSONL or `@microsoft/m365-copilot-eval` outputs offline.
- **[Contoso Fabric IQ Seed Kit](../samples/contoso/README.md)** and **[Work IQ Seed Kit](../samples/work-iq/README.md)** — Deterministic `@contoso.com` star-schema CSVs and synthetic M365 documents.
- **[Public Readiness Validation Checklist](validation/public-readiness-checklist.md)** — Offline verification checks prior to publishing results or releases.
