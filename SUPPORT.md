# Support

This is a community reference implementation provided as-is without formal SLAs or Microsoft product support.

* **Self-service diagnostics**: run `cfeval doctor --strict` and consult [Troubleshoot Common Issues](docs/how-to/troubleshoot.md) and [Platform Status](docs/reference/platform-status.md) first.
* **Questions and bugs**: if GitHub Issues are enabled on the repository (or your fork), use the bug/feature templates and attach scrubbed `cfeval doctor` output plus an offline `--mock` reproduction where possible. Remove all tenant IDs, workspace/item GUIDs, UPNs, and customer data before sharing (use `@contoso.com` placeholders).
* **Security disclosures**: never open public issues for security vulnerabilities or leaked credentials; follow [SECURITY.md](SECURITY.md) and review [Threat Model](docs/responsible-use/threat-model.md).
* **Microsoft product support**: for platform issues with Microsoft 365 Copilot, Microsoft Fabric, Power BI, or Microsoft Foundry, use Microsoft's official support channels.
