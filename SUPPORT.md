# Support

## How to file issues and get help

This project uses [GitHub Issues](../../issues) to track bugs, golden-set proposals and build tasks. Please search the existing issues before filing a new one to avoid duplicates. For a new bug or request, open an issue with the matching template.

For questions about using the harness, start with the [documentation index](docs/README.md) and the [implementation plan](docs/PLAN.md), then open an issue if your question is not answered there.

**Do not** include tenant identifiers, user names, tokens or customer data in an issue. See [SECURITY.md](SECURITY.md) for anything security-related.

## Microsoft Support Policy

This repository is a field-built reference implementation and demo. Support is limited to the resources listed above; it is not covered by Microsoft Customer Service and Support. For support with the Microsoft products it exercises (Microsoft 365 Copilot, Microsoft Fabric, Power BI, Copilot Studio, Microsoft Foundry), use the product's standard support channels.
