# Support

This is a community accelerator with no formal support. Microsoft doesn't support it.

* **Questions and bugs**: open a GitHub issue with the `cfeval doctor` output, the command you ran, and the error.
  Remove tenant IDs, user names and any customer data first.
* **Product issues** with Microsoft 365 Copilot, Microsoft Fabric or Microsoft Foundry: use those products' normal
  support channels.
