# Agents and the routing policy

This folder holds everything that steers how Copilot chooses a data source, so that a change to it is reviewed, versioned and measured like code.

| Path | What it is | Built by |
|---|---|---|
| [`policy/routing-policy.md`](policy/routing-policy.md) | The **single routing policy**: which certified model owns which business terms, disambiguation rules, forbidden sources, the answer contract and when to clarify or refuse. | Bootstrap (seeded from PLAN §4.2, §9.2) |
| [`declarative/`](declarative/README.md) | The Microsoft 365 Copilot declarative agent with the Fabric capability (manifest v1.9), driven at L2 by the Agent Evaluations CLI. | P4.1, P4.2, P4.4 |
| [`copilot-studio/`](copilot-studio/README.md) | Optional Copilot Studio agent assets (test-set CSV, notes). | P7.1, only if ADR-004 is positive |

## The routing policy is used verbatim by every layer

PLAN §9.2: one policy, used as-is by

- **L1**: the system prompt of the reference orchestrator (Azure OpenAI model + Fabric IQ MCP), together with the answer contract (P3.2);
- **L2**: the declarative agent's instructions and its `fabric-routing` agent skill, generated by `scripts/build_agent.py` (P4.1);
- **L3**: the Copilot Chat API `additionalContext` in the `policy_context` variant (P6.1).

Because every layer receives the same words, a difference between layers comes from the orchestrator, not from different instructions. That is what makes the L0/L1/L2/L3 failure triage trustworthy.

### Editing rules

- Change the policy only through a pull request: the PR gate runs the L0-L1 suite and shows the effect. Deleting the "revenue means gross" rule is one of the scripted regression demos (PLAN §12).
- Keep it under **8,000 characters** once rendered: the declarative agent's instructions are generated from it.
- Name business content (models and reports), never endpoints, tool names or authentication details (PLAN §9.7).
- `{{report_url:<model_key>}}` placeholders are filled in at build time from the tenant's report URLs, which are never committed.
